## Decision records — read this system first

Every non-trivial decision in this repo is recorded under `reports/DEC-*.md`, governed by
`instructions/DECISION-RECORDS.md`. Before proposing or changing anything: read
`reports/DECISIONS.md` (principles first); grep the records for the subject (a `revisit` class
of `none` is settled — don't reopen; a record carrying human judgment rests on a call you
can't re-derive — read it first); and when you settle a decision, file a record and regenerate
the index (`python3 scripts/decision_index.py`). Binds Cowork and Claude Code identically —
see `CLAUDE.md`.
