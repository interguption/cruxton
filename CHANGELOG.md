# Changelog — decision-records method

## 1.0.0 — 2026-08-29
First version, extracted from the Steelyard reference implementation. Slug IDs that name the
question; engineering / stance / design kinds; the three-layer capture of "why" (human_crux,
Human reasoning, Reasoning provenance) with a seven-type provenance taxonomy; outbound-only
edges with a generated, validated index; principles and per-area views derived, not filed;
records stay put (paths and ids are permanent). See `reports/` for the genesis ledger.
